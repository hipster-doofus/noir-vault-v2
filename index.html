About Noir Vault v2

Noir Vault v2 is an AI-powered discovery engine for public domain cinema. Each run of the GitHub Actions workflow dynamically searches the Internet Archive using configurable keywords, genre, and era filters.

Films are processed by PySceneDetect (AdaptiveDetector) to identify cinematic cuts. Three random scenes per film are extracted, transcoded to 1080p H.264, and analysed by Gemini AI to produce descriptions, mood analysis, and noir trope identification.

Metadata is stored in Supabase (PostgreSQL) and scene clips are attached to GitHub Releases. All films are verified public domain from Archive.org.
